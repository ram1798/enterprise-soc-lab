# Security Automation Scripts

## Overview
This directory contains automation and security
testing scripts developed for the Enterprise SOC Lab.

## Contents
- Bash automation scripts
- PowerShell scripts
- Environment setup scripts
- Security validation scripts
- Controlled log generation
- Detection testing utilities
- System health checks

## Objective
Develop scripting and automation skills
to improve SOC operational efficiency.

## Script Documentation
Each script should include:
- Purpose
- Requirements
- Usage instructions
- Expected output
- Security considerations

All testing scripts are intended for authorized,
isolated laboratory environments.
