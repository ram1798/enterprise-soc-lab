# Threat Detection Rules

## Overview
This directory contains custom security detection
rules and testing procedures developed for the
Enterprise SOC Lab.

## Contents
- Custom Wazuh detection rules
- Brute-force login detection
- Suspicious authentication activity
- Privilege escalation detection
- MITRE ATT&CK technique mappings
- Detection testing and validation
- False-positive analysis

## Objective
Develop detection engineering skills by creating,
testing, and refining security rules.

Each implemented rule will include:
- Detection objective
- Required log source
- Rule logic
- MITRE ATT&CK mapping
- Testing methodology
- Expected results
- Known limitations
