# Security Incident Reports

## Overview
This directory contains structured investigation
reports generated during controlled attack
simulations in the Enterprise SOC Lab.

## Contents
- Security incident summaries
- Alert investigation findings
- Log analysis evidence
- Incident timelines
- Indicators of compromise (IOCs)
- MITRE ATT&CK mappings
- Containment recommendations
- Lessons learned

## Objective
Demonstrate incident investigation and response
skills through evidence-based analysis.

All incidents are simulated within an authorized,
isolated laboratory environment.
