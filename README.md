# Enterprise SOC Lab 
## Project Overview 
 This project will document the process of designing, implementing, and testing a virtualized enterprise-style security operations center.
 
  The objective is to develop a lab that shows the practical side of security monitoring, threat detection, log analysis, incident investigation, and incident response.

### Planned Technology Stack 
- **Virtualization:** Oracle VirtualBox
- **SIEM and XRR:** Wazuh
- **Operating Systems:** Ubuntu Linux and Windows
- **Network Monitoring:** Suricata
- **Attack Simulation:** Controlled Testing Environment
- **Version Control:** GitHub and Git

### Project Objective 
1. Design a secure virtual network architecture.
2. Deploy and configure a centralized monitoring platform.
3. Collect and analyze Windows and Linux security logs.
4. Simulate and detect selected attack techniques.
5. Investigate security alerts and document findings.
6. Develop incident response reports and detection rules.
